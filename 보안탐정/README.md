# 🕵️ 사이버 탐정: 해커를 찾아라!

내 Windows 컴퓨터에 해킹 흔적이 있는지 **게임처럼** 조사하는 프로그램이에요.

## 실행 방법

1. 이 폴더의 파일 4개를 내 컴퓨터의 한 폴더에 내려받아요.
2. **`보안탐정_시작.bat`**을 더블클릭해요.
   - 로그인 기록까지 보려면 마우스 오른쪽 버튼 → **관리자 권한으로 실행**을 눌러요.
3. 약 2분 동안 단서를 모은 뒤, 게임이 브라우저로 열려요.
4. 사건 카드 7개를 하나씩 조사하고, 마지막에 **최종 수사 보고서**를 확인해요.

`index.html`만 열면 연습용 **예시 사건**으로 플레이할 수 있어요.

## 조사하는 사건

| 사건 | 내용 |
| --- | --- |
| 🛡️ 경비원 점검 | 백신(Windows Defender), 방화벽, 원격 데스크톱 상태 |
| 🚨 붙잡힌 악성코드 | 백신이 발견한 악성코드 기록 |
| 🚪 문 두드린 흔적 | 최근 7일 로그인 실패와 외부 접속 기록 (관리자 권한 필요) |
| 📡 몰래 통신 추적 | 지금 인터넷과 연결된 프로그램과 그 주소 |
| 🚀 몰래 시작하는 프로그램 | 컴퓨터를 켤 때 자동으로 실행되는 프로그램 |
| 👤 수상한 계정 | 내가 모르는 사용자·관리자 계정 |
| 📦 새로 나타난 프로그램 | 최근 2주 동안 설치된 프로그램, 다운로드·임시 폴더에서 실행 중인 프로그램 |

## 안전 원칙

- 조사는 **읽기만** 하고 아무 설정도 바꾸지 않아요.
- "몰래 통신 추적"에서 수상한 프로그램을 **삭제**할 때는 한 번 더 묻고, 파일을 **휴지통**으로 옮겨요. 되돌릴 수 있어요.
- 정상 서명이 있는 프로그램과 Windows 시스템 파일은 지우지 않아요.
- 삭제 도우미는 내 컴퓨터 안(`localhost`)에서만 동작하고, 1시간 뒤 저절로 꺼져요.

## ⚠️ 주의

- 실행하면 같은 폴더에 **`report.js`**가 생겨요. 여기에는 계정 이름, 인터넷 주소 같은 **개인 정보**가 들어 있어요. 다른 사람에게 보내거나 인터넷에 올리지 마세요. (이 저장소의 `.gitignore`에 넣어 두었어요.)
- 이 프로그램은 "어떤 프로그램이, 어떤 주소에서" 들어왔는지까지 알려줘요. **실제로 누가** 했는지는 경찰 수사로만 알 수 있어요.
