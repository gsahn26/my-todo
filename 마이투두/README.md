# ✅ 마이투두

할 일을 적고, 체크하고, 지우는 **간단한 할 일 목록**이에요.

## 실행 방법

- **가장 쉬운 방법**: `index.html`을 더블클릭해서 브라우저로 열어요.
- **주소로 열기**: [Node.js](https://nodejs.org)가 있다면 이 폴더에서 아래 명령을 실행하고 http://localhost:3000 에 들어가요.

  ```
  node server.js
  ```

## 할 수 있는 것

| 기능 | 방법 |
| --- | --- |
| ➕ 추가 | 입력창에 쓰고 **추가** 버튼 또는 Enter |
| ☑️ 완료 | 체크박스를 누르면 줄이 그어져요 |
| ✕ 삭제 | 항목 오른쪽의 ✕ |
| 🧹 정리 | **완료 항목 지우기**로 끝낸 일만 한 번에 지워요 |

## 저장

할 일은 **내 브라우저 안에만** 저장돼요(`localStorage`). 인터넷으로 보내지 않고, 새로고침해도 남아 있어요.
다른 브라우저나 다른 컴퓨터에서는 따로 저장돼요.
